Versions

The Current Version of ChairGun USE is: 4.4.1 — Major Code Cleanup and Some Enhancements.

I ran the project through a static code analyzer, and found another infinite loop and a myriad of other problems and potential problems. So I've combed through the code numerous times, fixing as many of the problems in it as I reasonably could.

Most of these were left over from the Original Developer, though some were likely caused in my decompilation work. Among the more visible of the fixes:

Fixed the Reticle dialog that I seem to have broken in version 4.4.0. This is important if you wish to easily see what your selected reticle looks like.

Fixed many problems with the Pellets dialog that were present in the Original Developer's final release. I also added the Pellets Database file name above the pellets table so you can easily see what database file you are working with.

Note: If you choose to load an Alternative Pellets Database from a location other than the ChairGun4/Pel directory, ChairGun-USE will copy the database you have selected to the ChairGun4/Pel directory with the same file name, and will save any updates that you make to it — not to the original database file you selected.

Also, ChairGun-USE will remember your alternative database and load it from then on each time you start the program, until you load a different one.

Fixed several problems in the Scopes dialog left over from the Original Developer's final release. I also combined the Current Scopes and Discontinued Scopes into one dialog, and removed the latter. So now all of the scopes are in one dialog. It's much cleaner and simpler.

I have fixed all of the bugs that I know of; so if you find any, feel free to bring them to my attention.

4.4.0 — This is Primarily a Bug Fix, with some other internal modifications.

The Install Process has also been Greatly Simplified, making it much easier to install than the initial release of ChairGun-USE.

This update fixes the following bugs:

  • In the “Embellishments” menu, the following “Right Side Markers” put the program into an infinite loop, causing the program to freeze.
    • Minutes of Arc
    • Clicks
    • MilliRadians (mils)
  • A few other minor bugs.

It is Highly Recommended that all users of the ChairGun USE Initial Realase (4.3.9) install this update, as you could potentially damage your computer trying to stop the program if it hangs like this.

I damaged mine trying to fix this. I wouldn’t want to see that happen to any of you.
